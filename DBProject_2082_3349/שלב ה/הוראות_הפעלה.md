# הוראות הפעלה – ממשק גרפי (שלב ה') 🦁

לפרויקט זה קיימות **שתי גרסאות** של ממשק גרפי לבחירתכם:
1. 🌐 **הגרסה המודרנית (מומלץ בחום להגשה!):** ממשק אינטרנט מתקדם ומעוצב מבוסס **React + FastAPI** עם עיצוב יוקרתי (Dark Mode, Glassmorphism, גרפים אינטראקטיביים ואנימציות).
2. 🖥️ **הגרסה הפשוטה:** ממשק שולחני קלאסי מבוסס פייתון ו-**Tkinter** בתיקייה `gui_app`.

שתי הגרסאות מתחברות לאותו מסד נתונים PostgreSQL ומאפשרות ניהול מלא ותקין.

---

## 💾 שלב מקדים: התקנת מסד הנתונים וטעינת נתונים

### 1. הפעלת PostgreSQL
מומלץ להריץ את בסיס הנתונים דרך Docker מתיקיית השורש של הפרויקט:
```bash
docker compose up -d
```
*ודאו שהופעלו סקריפטי שלב ד' (`Function_*.sql`, `Procedure_*.sql`, `Trigger_*.sql`, `AlterTable.sql`).*

### 2. טעינת נתונים (seed)
כדי לראות חיות, שאילתות ופרוצדורות, יש להריץ את סקריפט הטעינה מתיקיית `gui_app` פעם אחת:
```bash
cd "שלב ה/gui_app"
pip install -r requirements.txt
python seed_database.py
```
הסקריפט יטען את כל הטבלאות (כולל טבלת 2000 חיות, וטרינרים, בדיקות בריאות וכו') ויתקין את הפונקציות הנדרשות.

## 🌐 אפשרות א': ממשק אינטרנט מתקדם (React + FastAPI) - מומלץ! ⭐

ממשק מודרני מרהיב הכולל דשבורד, גרף דינמי של חיות לפי בית גידול, מערכת לוח בקרה מלאה עם חיפוש ודפדוף, והרצת שאילתות ופרוצדורות בלחיצת כפתור.

### דרישות מקדימות
- **Python 3.10+**
- **Node.js (v18+)** מותקן במחשב.

### הרצת ה-Backend (פייתון)
פתח חלון טרמינל 1 והרץ:
```powershell
cd "שלב ה/backend"
pip install fastapi uvicorn psycopg2-binary python-multipart
uvicorn main:app --reload
```
*השרת ירוץ בכתובת:* `http://localhost:8000`

### הרצת ה-Frontend (React)
פתח חלון טרמינל 2 והרץ:
```powershell
cd "שלב ה/frontend"
npm install
npm run dev
```
*האתר יפתח בדפדפן בכתובת:* `http://localhost:5173`

## 🖥️ אפשרות ב': ממשק שולחני קלאסי (Python + Tkinter)

ממשק פשוט העונה על דרישות המינימום של שלב ה'.

### הרצה
פתח חלון טרמינל והרץ:
```powershell
cd "שלב ה/gui_app"
pip install -r requirements.txt
python main.py
```

### פרטי התחברות למסך הכניסה של Tkinter:
- **שרת:** `localhost`
- **פורט:** `5432`
- **שם בסיס נתונים:** `zoo_db`
- **משתמש:** `postgres`
- **סיסמה:** `mysecretpassword` (או הסיסמה האישית שלך)
