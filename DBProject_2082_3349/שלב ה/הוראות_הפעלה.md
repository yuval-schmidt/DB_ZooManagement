# הוראות הפעלה – ממשק גרפי (שלב ה')

## דרישות מקדימות

1. **Python 3.10+** מותקן במחשב.
2. **PostgreSQL** פעיל עם בסיס הנתונים של הפרויקט (כולל שלבים א–ד: טבלאות, אינטגרציה וטרינרית, פונקציות ופרוצדורות).
3. מומלץ להריץ את בסיס הנתונים דרך Docker מהשורש של ה-repository:
   ```bash
   docker compose up -d
   ```
4. לוודא שהופעלו סקריפטי שלב ד' (`Function_*.sql`, `Procedure_*.sql`, `Trigger_*.sql`, `AlterTable.sql`).

## התקנה

```bash
cd DBProject_2082_3349/שלב ה/gui_app
pip install -r requirements.txt
```

## טעינת נתונים (חובה בפעם הראשונה)

בסיס `zoo_db` ב-Docker מגיע לרוב רק עם טבלת `habitat`. כדי לראות חיות, שאילתות ופרוצדורות:

```bash
python seed_database.py
```

הסקריפט טוען מ-CSV (מינים, תזונה, 2000 חיות, רשומות בריאות), מתקין מחלקה וטרינרית (שלב ג') ופונקציות/פרוצדורות שלב ד'.

אם רק חסרה טבלת `veterinarian` (שגיאה בפונקציית הווטרינר), הריצו בלי למחוק נתונים:

```bash
python install_vet.py
```

## חיבור לבסיס הנתונים

במסך הפתיחה יש להזין:

| שדה | ברירת מחדל |
|-----|------------|
| שרת | localhost |
| פורט | 5432 |
| שם בסיס נתונים | **zoo_db** (לא postgres!) |
| משתמש | postgres |
| סיסמה | mysecretpassword (ברירת מחדל ב-Docker) |

> העתיקו `.env.example` ל-`.env` בשורש הפרויקט אם משתמשים ב-docker compose.

ניתן לעקוף דרך משתני סביבה:

```bash
set DB_HOST=localhost
set DB_PORT=5432
set DB_NAME=your_db_name
set DB_USER=your_user
set DB_PASSWORD=your_password
python main.py
```

## מבנה הממשק

1. **מסך כניסה** – הגדרת חיבור ל-DB.
2. **תפריט ראשי** – גישה לכל הטבלאות, שאילתות ופונקציות.
3. **חלון CRUD לכל טבלה** – לשוניות: שליפה | הוספה | עדכון | מחיקה.
   - בשליפה: מפתחות זרים מוצגים כ**שמות** (לא מזהים).
   - בעדכון: הזנת מפתח → **טען רשומה** → עריכה → שמירה.
4. **שאילתות שלב ב'** – לפחות 4 שאילתות מהפרויקט.
5. **פונקציות ופרוצדורות שלב ד'** – 2 פונקציות, 2 פרוצדורות + הדגמת Trigger.
